# COBOL Account Management System Test Plan

This plan captures the business behavior currently implemented by `main.cob`, `operations.cob`, and `data.cob`. The **Actual Result**, **Status**, and **Comments** columns are intentionally left for stakeholder execution. Unless a test says otherwise, execute tests in one program run so that balance changes can be verified across operations.

## Execution Notes

- Record one result per test case in **Actual Result**, then mark **Status (Pass/Fail)** against the expected behavior agreed with stakeholders.
- For tests that alter the balance, either run them in the stated order or reset/restart the application as specified.
- Monetary precision, input validation, field overflow, unsupported operations, and persistence between separate launches are open modernization decisions where the current COBOL implementation is silent or limited.
